# 《余灯》实施基线 v1.0

依据用户在本任务中确认的《完整实施方案：人物、玩法与美术执行规格》。本文、角色数据和自动化用例共同作为实现基线；旧 IMPLEMENTATION_DRAFT_SUPERSEDED.md 仅供历史追溯，不能作为实现依据。

## 成品
45–60 分钟体验目标（最终需 Windows 人工实测），Unity 6.0 LTS / URP / uGUI+TMP / New Input System，写实比例简模的2.5D剖面、固定斜俯正交镜头、可探索车厢。玩家普通乘客在07小憩，被制动、行李滑落和失电惊醒，通过行动与承诺逐渐获得协调能力，没有天然指挥权。

核心循环：探索→信息→协商→确认计划→真实执行→根据结果调整。开场、教程、四NPC、五区域、两路线、四类结局、人物后日谈、存档、设置、帮助、环境音全部交付。真实 v2 是主体验；录制/预设回应明确标识离线演练，不能称为真实AI。文字对白，无TTS、无复杂口型。

TECH-04：世界事实/认知/说法/笔记/合同/任务/物品分存；报告不自证，观察与可信结果带来源；私聊/群聊按实际位置门和通信受众；履约须真实行动。
